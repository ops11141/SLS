# تقارير الصيانة — SLS

واجهة عربية متجاوبة لتنظيم تقارير الصيانة.

## أنواع التقارير المدعومة
- تقرير وردية الصيانة.
- تقرير الأعمال المجدولة.
- الانقطاعات المتجاوزة 3 ساعات.
- الانقطاعات المتجاوزة 6 ساعات.

## الوضع الحالي
هذه نسخة واجهة أولية مستقلة. التقارير التي يتم إدخالها تحفظ في localStorage داخل المتصفح الحالي فقط. لا توجد قاعدة بيانات مركزية موصولة بعد؛ لذلك لن تظهر البيانات تلقائيًا على أجهزة الموظفين الآخرين.

## النشر على GitHub Pages
من إعدادات المستودع افتح Settings → Pages، ثم اختر النشر من الفرع main والمجلد / (root). بعد تفعيل النشر، يكون الرابط المتوقع:
https://ops11141.github.io/sls/
